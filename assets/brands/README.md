# Brand icons

These local SVG files are official logo artwork retained for the site’s outbound links:

- `github-invertocat.svg` — downloaded from GitHub’s official logo package: <https://brand.github.com/GitHub_Logos.zip>. GitHub’s logo guidance: <https://brand.github.com/foundations/logo>.
- `orcid.svg` — official ORCID iD icon downloaded from <https://orcid.org/assets/vectors/orcid.logo.icon.svg>. ORCID brand guidelines: <https://info.orcid.org/brand-guidelines/>.
- `scix-mark.svg` — symbol extracted from the official SciX homepage navigation logo: <https://scixplorer.org/>.

The marks remain the property of GitHub and SciX/SAO ADS, respectively. Keep them linked to those services and do not recolor, distort, or use them to imply endorsement.
