Software

I build open-source tools for stellar astrophysics, from simulating starspots and light curves to interpolating stellar evolution models.

butterpy: simulations of star spot evolution and light curves

A lightweight software package to generate physically realistic star spot distributions, butterfly diagrams, and light curves. I mainly use butterpy to generate machine learning training sets of light curves from which we can infer rotation periods. This framework has been used to measure rotation periods from Kepler and TESS, and I will use it for the Roman Galactic Bulge Time Domain Survey as well.

GitHub repository SciX papers

kiauhoku: interpolate stellar evolution models

A tool to make stellar characterization and parameter estimation more accessible. Kiauhoku is a model grid interpolator with access to pre-installed grids. It includes statistical sampling tools to aid with parameter inference, isochrone fitting, gyrochronology, and more.

GitHub repository SciX papers
